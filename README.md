## 테스트 목록

#### 단위 테스트
- [ ] 전체 태스크 중 Done 상태의 비율로 완료율을 계산해야 한다.
- [ ] 태스크가 상태에 맞는 컬럼에 분류되어야 한다.
- [ ] 각 컬럼의 태스크 개수가 실제 해당 상태의 태스크 수와 일치해야 한다.
- [ ] 태스크 생성 후 해당 상태의 컬럼에 추가되어야 한다.
- [ ] 태스크 생성 후 완료율이 재계산되어야 한다.

#### UI 테스트
- [ ] 새 태스크 생성 버튼을 누르면 생성 다이얼로그가 열려야 한다.
- [ ] 생성 다이얼로그에서 정상적인 값들을 입력 후 생성 버튼을 누르면 칸반 보드 리스트에 표시되어야 한다.

## UI 목록

### 칸반 보드 헤더
 - [ ] 타이틀
 - [ ] 진행도
 - [ ] 프로그레스 바
 - [ ] 새 태스트 생성 버튼

### 칸반 보드 리스트
 - [ ] 타이틀 로우
   - 상태명
   - 카드 갯수
 - [ ] 카드 목록

### 기타
 - [ ] 스낵바

## 기능 목록
- [ ] 칸반 보드에 3개 컬럼(To Do, In Progress, Done)을 표시한다.
- [ ] 각 컬럼에 해당 상태의 태스크 카드를 표시한다.
- [ ] 각 컬럼 헤더에 해당 상태의 태스크 개수를 뱃지로 표시한다.
- [ ] Done 상태의 태스크 수를 기반으로 완료율을 계산하여 표시한다.
- [ ] 완료율에 따라 프로그레스 바를 채운다.
- [ ] "+ 새 태스크 생성" 버튼을 눌러 태스크 생성 다이얼로그를 연다.
